# مواقيت الصلاة — Ahmed Nx

تطبيق ويب لمواقيت الصلاة والأذكار يعمل **بدون إنترنت** بعد أول فتح، ويمكن تثبيته على الهاتف كتطبيق.

**رابط التشغيل:** https://ahmednx-hub.github.io/prayer-times/

## أهم المميزات

- **مواقيت الصلاة** تُحسب على جهازك بدون إنترنت، بعدة طرق حساب، مع التاريخ الهجري وضبط دقيق لكل صلاة.
- **تنبيهات** للصلوات وقبلها، وتنبيه قبل خروج وقت الصلاة، وأصوات مختلفة لكل نوع، ووضع عدم الإزعاج.
- **الأذكار:** أذكار الصباح والمساء، ومكتبة حصن المسلم مرتّبة في مواضيع، والمفضلة، والمسبحة، وعدّاد الأذكار.
- **ورد القرآن اليومي** بعدّاد صفحات أو أجزاء وأهداف وشارات تشجيعية.
- **سجل المواظبة:** تسجيل الصلوات وقضاء الفوائت، وخريطة شهرية وسنوية، وملخص أسبوعي.
- **النوافل والصيام:** الضحى وقيام الليل والإمساك والإفطار وصيام الاثنين والخميس والأيام البيض.
- **تقارير** شهرية كصورة أو ملف أو طباعة PDF.
- **مظهر قابل للتخصيص:** ثيمات جاهزة وثيمات مخصصة، وخطوط الأذكار، ووضع اليد الواحدة، ووضع القراءة الليلي.
- **عربي وإنجليزي**، ويتكيّف مع الهاتف والتابلت والكمبيوتر.
- **نسخ احتياطي:** تصدير واستيراد مضغوط، وثلاث نسخ تلقائية داخل الجهاز.

## التثبيت على الهاتف (أندرويد)

1. افتح الرابط أعلاه في متصفح Chrome.
2. من قائمة المتصفح اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
3. اسمح بالإشعارات والموقع عند الطلب.

لتصل التنبيهات بشكل أفضل: أوقف تحسين البطارية لمتصفح Chrome، ولا تُنهِ التطبيق من قائمة التطبيقات الأخيرة.

## الخصوصية

كل بياناتك (الإعدادات والسجل والمفضلة) تُحفظ **على جهازك فقط** ولا تُرسل إلى أي خادم.
